# SENTEC Landing Page Design Direction

## Three stylistic approaches

### Theme Name: Signal / Structure
Very dark editorial engineering interface with a warm signal orange, calibrated grids, and a logo that assembles like an active system.
**Probability:** 0.07

### Theme Name: Field Notes
Light paper-like scientific journal aesthetic with blueprint blue, orange annotations, and tactile diagram fragments.
**Probability:** 0.03

### Theme Name: Orbit / Pulse
Atmospheric midnight interface with luminous orbital rings and a more cinematic animated mark.
**Probability:** 0.08

## Chosen approach: Signal / Structure

### Design Movement
Contemporary Swiss-influenced editorial design fused with industrial control-panel graphics and kinetic identity systems.

### Core Principles
1. Make the logo feel like a live instrument: parts calibrate, lock, and emit a restrained signal.
2. Use asymmetry and editorial pacing rather than generic centered hero layouts.
3. Pair high-contrast ink-black surfaces with one ownable orange signal color and quiet steel-blue support tones.
4. Let engineering details become navigation cues: ticks, brackets, status labels, coordinates, and measured spacing.

### Color Philosophy
The near-black background creates focus and seriousness, while signal orange (#F15A24) behaves like a live indicator rather than decoration. Cool steel and muted blue-gray tones provide technical depth without competing with the brand mark. White is reserved for the main narrative and active states.

### Layout Paradigm
A split hero with an editorial copy rail on the left and a large, interactive orbiting logo system on the right. Subsequent sections use offset columns, slim rails, and card clusters with deliberate empty space instead of repetitive centered blocks.

### Signature Elements
- A kinetic SENTEC mark with orbiting field nodes and an orange calibration sweep.
- Thin measurement ticks, corner brackets, and monospaced system labels.
- A persistent “signal line” motif that connects the hero to the content sections.

### Interaction Philosophy
Interactions should feel instrument-like: hover states brighten a node, buttons compress slightly, and the logo reacts to pointer position with subtle parallax. Motion should be precise and quiet, never noisy or gimmicky.

### Animation
The hero mark enters through a staged assembly: outer ring draws in, core symbol scales from 96% with opacity, field nodes lock into orbit, and a signal sweep travels once across the system. After entrance, rings rotate at different speeds, nodes bob by a few pixels, and the mark responds to pointer movement. All non-essential motion pauses under prefers-reduced-motion.

### Typography System
Use Space Grotesk for expressive headings and IBM Plex Mono for metadata, labels, and navigation accents. Body copy uses a clean system sans stack for readability. Headlines are tight and weighty, with occasional italic emphasis; technical labels are uppercase, tracked, and small.

### Brand Essence
SENTEC is the student engineering society that turns curiosity into capability through real projects, shared practice, and visible impact.
**Personality:** exacting, kinetic, generous.

### Brand Voice
Headlines are concise and declarative. CTAs feel like invitations into a working system, not generic conversion language.
- “Build what the brief leaves out.”
- “Enter the signal.”

### Wordmark & Logo
Use the provided geometric mark as the visual anchor, paired with a custom-spaced SENTEC wordmark. The hero version should treat the mark as an instrument: the symbol is assembled from linework, then stabilized by orbital rings and orange field nodes.

### Signature Brand Color
Signal Orange — `#F15A24`.

## Style Decisions

- The light theme is a **drafting-table relief plane**, not a separate generic site. Keep dark instrument fields prominent in the hero, project panels, exact-logo module, and imagery.
- Every route carries one structural calibration cue: an orange signal line, measured tick strip, orbit fragment, bracket, or coordinate label.
- Portraits and visual archive cards use consistent dark technical overlays, restrained orange metadata, and deliberate crops so external media stays inside the SENTEC system.
