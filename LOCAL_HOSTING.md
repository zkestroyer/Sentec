# Running SENTEC Locally Without Manus Storage

The repository’s root-level `assets/` folder contains the two original SENTEC logo files and three technical textures. The standard preview keeps using the hosted `/manus-storage/...` URLs, but the local commands below copy those repository files into Vite’s public directory and switch the application to `/assets/...` URLs.

## Local development

| Step | Command | Result |
|---|---|---|
| Install dependencies | `pnpm install` | Installs the project packages. |
| Start local mode | `pnpm dev:local` | Copies `assets/` into `client/public/assets/`, loads `.env.localhost`, and starts the site with local URLs. |
| Open the site | `http://localhost:3000` | Shows the app with all five local image files. |

The `client/public/assets/` directory is generated by the command and intentionally ignored by Git. The source-controlled files remain in the repository root under `assets/`.

## Local production build

Run the following when preparing a self-hosted build:

```bash
pnpm build:local
pnpm start
```

`pnpm build:local` creates `dist/` with an `assets/` directory in the browser output. You can deploy that output to any normal Node-compatible or static-hosting setup that supports this project’s build command.

## Replacing an image

Replace the matching file in the root `assets/` directory, keeping the filename unchanged. Then rerun `pnpm dev:local` or `pnpm build:local`; the preparation script copies the new file automatically. The runtime mapping lives in `client/src/lib/assets.ts` if you deliberately rename an asset.

> **Note:** Do not commit `client/public/assets/`. Commit changes to the root `assets/` directory instead.
